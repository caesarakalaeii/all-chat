<objective>
Integrate YouTube Listener with Phase 1 Message ID Registry, enabling YouTube message IDs to be tracked for deletion event matching.

Purpose: YouTube deletion events reference platform message IDs (from msg.Id), but message-processor needs internal UUIDs to remove messages from overlays. This plan follows the Twitch pattern: add YouTube message IDs to registry at capture point in the listener, enabling registry lookups when deletion events arrive.

Output: YouTube messages registered with platform IDs, deletion events successfully matched via registry, and end-to-end deletion flow verified.
</objective>
