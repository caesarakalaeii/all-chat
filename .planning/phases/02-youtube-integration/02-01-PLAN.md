<objective>
Map YouTube API deletion events (messageDeletedEvent, userBannedEvent) to Phase 1 unified deletion schema in the YouTube Listener parser.

Purpose: YouTube API already provides deletion events in polling responses (lines 98-116 in parser.go), but they use display event types ("message_deleted", "user_banned") instead of the internal deletion event schema. This plan converts them to Phase 1's `EventType = "message_deletion"` with `deletion_type` field, enabling them to flow through the existing deletion pipeline.

Output: Modified parser producing Phase 1-compatible deletion events with comprehensive test coverage.
</objective>

Modify the YouTube parser's ParseChatMessage function to convert deletion events to Phase 1 schema:

**Current state (lines 98-116):**
- `msg.Snippet.MessageDeletedDetails` → `eventType = "message_deleted"` (display event)
- `msg.Snippet.UserBannedDetails` → `eventType = "user_banned"` (display event)

**Required changes:**

1. **Single message deletion (lines 98-103):**
   - Change `eventType = "message_deleted"` → `eventType = "message_deletion"`
   - Change `text = "Message deleted"` → `text = ""` (deletion events don't need text)
   - Change `eventData["deleted_message_id"]` → `eventData["target_msg_id"]`
   - Add `eventData["deletion_type"] = "single"`

2. **User ban/timeout (lines 104-116):**
   - Change `eventType = "user_banned"` → `eventType = "message_deletion"`
   - Change `text = "User banned"` → `text = ""`
   - Change `eventData["banned_user_id"]` → `eventData["target_user_id"]`
   - Change `eventData["banned_user_name"]` → `eventData["target_username"]`
   - Add `eventData["deletion_type"] = "batch"`
   - Keep `ban_type` and `ban_duration_seconds` fields unchanged (optional metadata for logging)

3. **Add YouTube message ID to tags (line ~119):**
   - After creating tags map, add: `tags["youtube_message_id"] = msg.Id`
   - This enables registry integration in Plan 02-02

**Phase 1 schema reference:**
- EventType: "message_deletion" (checked in message-processor line 284)
- Deletion types: "single", "batch", "clear"
- Single deletion: requires target_msg_id (platform message ID)
- Batch deletion: requires target_user_id (user identifier)

**Do NOT change:**
- Regular message handling (TextMessageDetails, SuperChatDetails, etc.)
- Super Chat, membership, gift events
- Parser structure or function signatures
- Error handling patterns

func TestParseYouTubeDeletionEvents(t *testing.T) {
    parser := NewParser()

    t.Run("MessageDeletedEvent", func(t *testing.T) {
        msg := &youtube.LiveChatMessage{
            Id: "CjoKGkNKem93WjJkQkljQ0ZRcWFRZ29kSnU4T0JBEhxDTXV4c2YyZEJJY0NGUWVQdXdvZDFjd0JRQSgB",
            Snippet: &youtube.LiveChatMessageSnippet{
                Type: "messageDeletedEvent",
                PublishedAt: "2024-01-15T10:30:00.000Z",
                MessageDeletedDetails: &youtube.LiveChatMessageDeletedDetails{
                    DeletedMessageId: "CjoKGkNKem93WjJkQkljQ0ZRcWFRZ29kSnU4T0JBEhxDTXV4c2YyZEJJY0NGUWVQdXdvZDFjd0JRQSgA",
                },
            },
            AuthorDetails: &youtube.LiveChatMessageAuthorDetails{
                ChannelId:   "UC_mod_channel_id",
                DisplayName: "ModeratorName",
            },
        }

        raw, err := parser.ParseChatMessage(msg, "UCxxxxxx", "stream123")
        require.NoError(t, err)

        // Verify Phase 1 deletion schema
        assert.Equal(t, "message_deletion", raw.EventType)
        assert.Equal(t, "single", raw.EventData["deletion_type"])
        assert.Equal(t, "CjoKGkNKem93WjJkQkljQ0ZRcWFRZ29kSnU4T0JBEhxDTXV4c2YyZEJJY0NGUWVQdXdvZDFjd0JRQSgA",
                     raw.EventData["target_msg_id"])

        // Verify YouTube message ID in tags

                     raw.Tags["youtube_message_id"])
