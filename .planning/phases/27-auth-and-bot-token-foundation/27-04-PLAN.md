Handler struct uses interfaces for testability:
```go
package handlers

import (
    "context"
    "encoding/json"
    "fmt"
    "io"
    "net/http"
    "strings"
    "time"

    "github.com/caesar/all-chat/services/auth-service/models"
    "github.com/gin-gonic/gin"
    "github.com/redis/go-redis/v9"
    "go.uber.org/zap"
)

// DiscordOAuthProvider is the interface DiscordHandler depends on (allows mocking in tests).
type DiscordOAuthProvider interface {
    GetAuthURL(state string) string
    ExchangeCode(ctx context.Context, code string) (accessToken string, err error)
    CheckBotPermissions(ctx context.Context, guildID string) ([]string, error)
}

// DiscordGuildRepo is the interface for guild persistence (allows mocking in tests).
type DiscordGuildRepo interface {
    UpsertGuild(ctx context.Context, guild *models.DiscordGuild) error
    DeleteGuild(ctx context.Context, userID, guildID string) error
    ListGuildsByUser(ctx context.Context, userID string) ([]*models.DiscordGuild, error)
    GetGuild(ctx context.Context, userID, guildID string) (*models.DiscordGuild, error)
    DeleteDiscordSourcesByGuildID(ctx context.Context, guildID string) error
}

type DiscordHandler struct {
    oauth       DiscordOAuthProvider
    repo        DiscordGuildRepo
    redis       *redis.Client
    botToken    string
    frontendURL string
    log         *zap.Logger
    httpClient  *http.Client
}

func NewDiscordHandler(
    oauth DiscordOAuthProvider,
    repo DiscordGuildRepo,
    redisClient *redis.Client,
    botToken, frontendURL string,
    log *zap.Logger,
) *DiscordHandler {
    return &DiscordHandler{
        oauth:       oauth,
        repo:        repo,
        redis:       redisClient,
        botToken:    botToken,
        frontendURL: frontendURL,
        log:         log,
        httpClient:  &http.Client{Timeout: 10 * time.Second},
    }
}
```

**HandleConnect** (JWT required): generates CSRF state, stores `state -> userID` in Redis for 10 min,
returns `{"bot_invite_url": "..."}`.

**HandleCallback** (public): validates state from Redis, exchanges code for token (stores token for
audit only — not used for subsequent calls), extracts `guild_id` from query params, calls
`CheckBotPermissions(guild_id)`. If missing permissions → return 403 with JSON
`{"error": "Bot is missing: View Channels, Send Messages"}` and do NOT save guild. If all
permissions present → UpsertGuild → redirect to `{frontendURL}/settings?discord=connected`.

Important: Do NOT trust `permissions` query param from callback (per RESEARCH.md anti-patterns).
Always re-fetch via `CheckBotPermissions`. Missing permissions is a 403 Forbidden (the bot was
invited but lacks the required access) — not a 400 Bad Request.

**HandleGetGuilds** (JWT required): calls `repo.ListGuildsByUser(userID)`, returns JSON array.

**HandleGetGuildChannels** (JWT required): verifies guild belongs to authenticated user via
`repo.GetGuild`. Calls `GET https://discord.com/api/v10/guilds/{guild_id}/channels` with
`Authorization: Bot {botToken}`. Filters to type=0 channels only. Groups by parent_id into
categories structure. Channels with no parent_id go in a synthetic `{"id": "", "name": "Uncategorized"}` category.

**HandleDisconnect** (JWT required): verifies guild belongs to authenticated user.
Best-effort: calls `DELETE https://discord.com/api/v10/users/@me/guilds/{guild_id}` with Bot token.
Logs error but continues if API fails (404 = already left = treat as success).
Always calls `repo.DeleteGuild(userID, guildID)` regardless of API result.
Always calls `repo.DeleteDiscordSourcesByGuildID(guildID)` regardless of API result.

```go
router.GET("/discord/callback", func(c *gin.Context) {

    }
```

Protected routes (inside the `protected` group):
```go
if discordHandler != nil {

}
```
