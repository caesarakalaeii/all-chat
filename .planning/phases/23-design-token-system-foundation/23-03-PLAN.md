  - .event-message[class*="like_aggregate"]
  - .event-message[class*="member"]
  - .event-message[data-platform="twitch|youtube|kick|tiktok|system"]

Migration approach:
1. Add @layer order declaration at TOP of file (before any rule bodies)
2. Wrap ALL rule bodies (except @keyframes) in @layer marketplace-themes { }
3. Remove every !important from property values — the layer wins via cascade order
4. @keyframes can stay OUTSIDE the layer (keyframe names are global, not cascade-layer-scoped)

WARNING: @keyframes MUST remain outside @layer or at the document scope — animations referenced
inside a layer still resolve to keyframes defined outside the layer.

Critical: The layer order declaration must also appear in events.css because overlay preview pages
load events.css independently (without globals.css in some contexts).

After migration, events.css structure:
```css
/* Cascade layer order — required for standalone overlay page context */
@layer base, design-system, marketplace-themes, user-overrides;

/* @keyframes stay at document scope (not inside layers) */
@keyframes event-bounce-in { ... }
@keyframes high-tier-glow { ... }
@keyframes event-icon-pulse { ... }
@keyframes heartbeat { ... }
@keyframes raid-sweep { ... }
@keyframes gift-explosion { ... }
@keyframes warning-pulse { ... }
@keyframes warning-shake { ... }

@layer marketplace-themes {
  /* All rule sets moved here, !important removed */
  .event-message { padding: 1.5rem; /* not !important */ ... }
  ...
}
```
