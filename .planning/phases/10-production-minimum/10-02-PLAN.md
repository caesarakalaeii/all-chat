Extend parser.go with new parsing functions:

1. parseSuperChat(renderer *LiveChatPaidMessageRenderer, channelID string) (*RawChatMessage, error)
   - EventType: "super_chat"
   - EventData: {"amount": "$5.00", "color": "#1e88e5", "amount_micros": 5000000}
   - Extract amount from PurchaseAmountText.SimpleText
   - Extract color from HeaderBackgroundColor (if available)
   - Handle empty message text (some Super Chats have no message)

2. parseSuperSticker(renderer *LiveChatPaidStickerRenderer, channelID string) (*RawChatMessage, error)
   - EventType: "super_sticker"
   - EventData: {"amount": "$2.00", "sticker_url": "https://...", "amount_micros": 2000000}
   - Extract sticker URL from Sticker.Thumbnails.Thumbnails[0].URL
   - Text field empty (stickers have no text)

3. parseMembershipWelcome(renderer *LiveChatMembershipItemRenderer, channelID string) (*RawChatMessage, error)
   - EventType: "member_joined"
   - EventData: {"level_name": "Member"}
   - Extract welcome text from HeaderSubtext
   - Distinguish from milestone by checking if HeaderSubtext contains "Welcome"

4. parseMembershipMilestone(renderer *LiveChatMembershipItemRenderer, channelID string) (*RawChatMessage, error)
   - EventType: "member_milestone"
   - EventData: {"months": 6, "level_name": "Member"}
   - Extract months from HeaderSubtext (regex: "Member for (\\d+) months?")
   - Extract level name from membership badge or default to "Member"

5. parseTickerEvent(action *AddLiveChatTickerItemAction, channelID string) (*RawChatMessage, error)
   - Detect underlying event type (Super Chat or Super Sticker)
   - Parse using parseSuperChat or parseSuperSticker
   - Add EventData["pinned"] = true and EventData["ticker_duration_sec"] = DurationSec
