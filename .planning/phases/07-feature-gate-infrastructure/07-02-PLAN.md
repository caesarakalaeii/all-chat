       ```go
       package handlers

       import (
           "net/http"
           "github.com/gin-gonic/gin"
           "github.com/jackc/pgx/v5/pgxpool"
           "github.com/redis/go-redis/v9"
           "go.uber.org/zap"
       )

       const featureGatesPubSubChannel = "feature-gates:invalidate"

       type FeatureGateResponse struct {
           FeatureKey  string `json:"feature_key"`
           IsPremium   bool   `json:"is_premium"`
           Description string `json:"description"`
       }

       type AdminFeatureGatesHandler struct {
           db     *pgxpool.Pool
           redis  *redis.Client
           logger *zap.Logger
       }

       func NewAdminFeatureGatesHandler(db *pgxpool.Pool, rc *redis.Client, logger *zap.Logger) *AdminFeatureGatesHandler { ... }
       ```

    2. Implement `ListGates(c *gin.Context)`:
       - Query: `SELECT feature_key, is_premium, description FROM feature_gates ORDER BY feature_key`
       - Return 200 with `[]FeatureGateResponse` (empty slice `make([]FeatureGateResponse, 0)` if no rows — marshals as `[]` not `null`)
       - On DB error: return 500 with `{"error": "failed to load feature gates"}`

    3. Implement `UpdateGate(c *gin.Context)`:
       - Read key from `c.Param("key")`
       - Bind request body using `*bool` pointer type to avoid Gin's `binding:"required"` rejecting `false`:
         ```go
         type updateFeatureGateRequest struct {
             IsPremium *bool `json:"is_premium"`
         }
         ```
       - Validate: if `req.IsPremium == nil`, return 400 with `{"error": "is_premium field required"}`
       - Execute: `UPDATE feature_gates SET is_premium = $1 WHERE feature_key = $2` — check `commandTag.RowsAffected()`. If 0, return 404 with `{"error": "feature gate not found"}`
       - On success: publish to Redis `feature-gates:invalidate` with the key as payload (best-effort — log warning on failure, do not return error since DB is already updated and TTL will catch up per D-09)
       - Return 200 with `{"feature_key": key, "is_premium": *req.IsPremium}`
       - Log: `logger.Info("Feature gate updated", zap.String("key", key), zap.Bool("is_premium", *req.IsPremium))`

    4. Write tests in `services/share-service/handlers/admin_featuregates_test.go`:
       - Use `httptest.NewRecorder()` + `gin.CreateTestContext()` pattern (consistent with shares_test.go)
       - For DB: use pgxmock (`github.com/pashagolub/pgxmock/v4`) or test against a real database if the project uses that pattern. Check shares_test.go for the established pattern.
       - For Redis publish: use miniredis or a mock redis client that records Publish calls
       - Cover all 6 behaviors listed above
       - CRITICAL: Test that `{"is_premium": false}` is accepted (not rejected) — this validates the `*bool` pointer approach

    Per D-13: PATCH /api/v1/admin/feature-gates/:key. Per D-14: toggle publishes invalidation.
