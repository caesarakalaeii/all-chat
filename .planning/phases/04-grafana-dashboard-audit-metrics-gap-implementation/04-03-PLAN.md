For each of auth-service, overlay-manager, and emote-service, add HTTP request metrics. Since these are Gin-based services, the cleanest approach is a Gin middleware that records every request.

**Approach: Gin middleware using promauto counters directly.**

Rather than importing GatewayMetrics (semantically wrong for non-gateway services), create a simple Gin middleware that uses the standard `http_requests_total` and `http_request_duration_seconds` counters. These metric names will be service-scoped via the `service` label.

For EACH service (auth-service, overlay-manager, emote-service):

1. In `cmd/main.go`, add a Gin middleware function (or a shared utility if it makes sense) that wraps all routes:
   ```go
   httpRequestsTotal := promauto.NewCounterVec(prometheus.CounterOpts{
       Name: "http_requests_total",
       Help: "Total HTTP requests",
   }, []string{"service", "method", "path", "status"})

   httpRequestDuration := promauto.NewHistogramVec(prometheus.HistogramOpts{
       Name:    "http_request_duration_seconds",
       Help:    "HTTP request duration",
       Buckets: prometheus.DefBuckets,
   }, []string{"service", "method", "path"})
   ```

   WAIT: promauto will PANIC if the same metric name is registered in multiple services running in the same binary. But these are SEPARATE binaries (separate pods), so reusing `http_requests_total` across services is SAFE — each service runs in its own process.

   However, check if any of these services already import shared/metrics/ — if so, use the existing pattern. If not, define the middleware locally in cmd/main.go.

   Add the middleware to the Gin router: `router.Use(metricsMiddleware(httpRequestsTotal, httpRequestDuration, serviceName))`.

   The middleware function:
   ```go
   func metricsMiddleware(requests *prometheus.CounterVec, duration *prometheus.HistogramVec, service string) gin.HandlerFunc {
       return func(c *gin.Context) {
           start := time.Now()
           c.Next()
           status := strconv.Itoa(c.Writer.Status())
           path := c.FullPath()
           if path == "" { path = c.Request.URL.Path }
           requests.WithLabelValues(service, c.Request.Method, path, status).Inc()
           duration.WithLabelValues(service, c.Request.Method, path).Observe(time.Since(start).Seconds())
       }
   }
   ```

2. Service names for labels: `"auth-service"`, `"overlay-manager"`, `"emote-service"`.

**overlay-manager additionally**: In overlay CRUD handlers, add business metrics:
   ```go
   bm.RecordSourceOperation("create", platform, "success")  // or "error"
   bm.RecordSourceOperation("delete", platform, "success")
   ```
   Initialize `metrics.NewBusinessMetrics()` in cmd/main.go and pass to handlers.

**emote-service additionally**: In emote lookup handlers (where 7TV/BTTV/FFZ APIs are called), record:
   ```go
   emoteRequestsTotal.WithLabelValues("emote-service", provider, "success").Inc()
   ```
   Use a local counter for emote API calls: `emote_api_calls_total` with labels `service`, `provider`, `result`.
