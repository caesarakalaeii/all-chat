  - Messages sent via WebSocket: `rate(gateway_messages_sent_total[5m])` by result

- Row "Overlay Subscriptions":
  - Active subscriptions: `gateway_overlay_subscriptions_active` (gauge, topk 10)
  - Subscription events: `rate(gateway_overlay_subscription_events_total[5m])` by event (subscribe/unsubscribe)

  - Source operations: `rate(allchat_source_operations_total[5m])` by operation
- Row "Emote Service":
  - API calls by provider: `rate(emote_api_calls_total[5m])` by provider, result
