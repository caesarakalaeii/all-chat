   - `handlePointerMove` via `useCallback` — direct DOM mutation on glow elements (NO useState):
     ```typescript
     const MAX_DIST = 520
     cardRefs.current.forEach((card, i) => {
       if (!card || !glowRefs.current[i]) return
       const glow = glowRefs.current[i]!
       const rect = card.getBoundingClientRect()
       const dx = Math.max(rect.left - e.clientX, 0, e.clientX - rect.right)
       const dy = Math.max(rect.top - e.clientY, 0, e.clientY - rect.bottom)
       const dist = Math.hypot(dx, dy)
       const intensity = Math.pow(Math.max(0, 1 - dist / MAX_DIST), 2)
       if (intensity < 0.003) { glow.style.opacity = '0'; return }
       glow.style.left = `${e.clientX - rect.left}px`
       glow.style.top  = `${e.clientY - rect.top}px`
       glow.style.opacity = String(Math.min(intensity * 1.35, 1))
     })
     ```
   - `useEffect` adds `pointermove` listener on window, cleanup removes it
   - Returns `{ cardRefs, glowRefs }`
