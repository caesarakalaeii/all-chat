**Replace (systematic token replacement):**
- `bg-white` → `bg-surface` (card/table backgrounds)
- `bg-gray-50` → `bg-surface-2` (header rows, hover states)
- `text-gray-900` / `text-gray-800` / `text-gray-700` → `text-text`
- `text-gray-600` / `text-gray-500` → `text-text-sub`
- `text-gray-400` → `text-text-dim`
- `border-gray-200` / `border-gray-300` → `border-border`
- `hover:bg-gray-50` → `hover:bg-surface-2`
- `shadow` / `shadow-sm` → `border border-border` (cards use border, not shadow, in dark theme)
- `window.confirm()` → `Dialog.Root` with destructive confirm pattern
- `alert()` → `toastManager.add()`
- Any `notification` state → `toastManager.add()`
- Spinner/loading → `Skeleton`

**New table wrapper structure:**
```tsx
<div className="max-w-7xl mx-auto px-4 py-8">
  <div className="flex items-center justify-between mb-6">
    <h1 className="text-2xl font-bold text-text">Users</h1>
    <span className="text-text-sub text-sm">{users.length} total</span>
  </div>

  {isLoading ? (
    <Card className="p-6 space-y-3">
      {Array.from({ length: 5 }).map((_, i) => (
        <Skeleton key={i} className="h-12 w-full rounded-lg" />
      ))}
    </Card>
  ) : (
    <Card className="overflow-hidden">
      <div className="overflow-x-auto">
        <table className="w-full text-sm">
          <thead className="bg-surface-2 border-b border-border">
            <tr>
              {/* columns: Username, Email, Role, Created, Actions */}
              <th className="text-left px-4 py-3 text-text-sub font-medium">Username</th>
              {/* ... */}
            </tr>
          </thead>
          <tbody className="divide-y divide-border">
            {users.map(user => (
              <tr key={user.id} className="hover:bg-surface-2 transition-colors">
                <td className="px-4 py-3 text-text font-medium">{user.username}</td>
                {/* ... */}
                <td className="px-4 py-3">
                  <div className="flex gap-2">
                    {/* Impersonate button (outline small) */}
                    {/* Ban/Unban button */}
                    {/* Delete button — wrap in Dialog */}
                  </div>
                </td>
              </tr>
            ))}
          </tbody>
        </table>
      </div>
    </Card>
  )}
</div>
```
