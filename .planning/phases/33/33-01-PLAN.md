# Plan 33-01: DB Migration + Go Model + API Passthrough

**Phase:** 33 — CSS Architecture Foundation
**Requirements:** VISM-01
**Status:** Not started

## Goal

Add `visual_settings JSONB` column to `overlay_configs`, update the Go model and repository to persist it, update the config handler to accept and return it, and update the TypeScript `OverlayConfig` type to include the new field.

## Success Criteria

1. `migrations/041_visual_settings.sql` applies without error; `overlay_configs` table has `visual_settings JSONB NOT NULL DEFAULT '{}'`
2. `migrations/041_visual_settings_down.sql` rolls back cleanly
3. `GET /api/v1/overlays/:id/config` response includes `"visual_settings": {}` (or populated object)
4. `PUT /api/v1/overlays/:id/config` with `{ "visual_settings": { "fontFamily": "Inter" } }` persists and returns the value unchanged
5. `GET /api/v1/overlays/public/:id/config` does NOT expose `visual_settings` (public endpoint is unchanged)
6. Frontend `OverlayConfig` type has `visual_settings?: Record<string, unknown>`

**`scanOverlayConfig`** — add `visual_settings` scanning:

```go
func scanOverlayConfig(row pgx.Row) (*models.OverlayConfig, error) {
    config := &models.OverlayConfig{}
    var displaySettingsJSON, filterSettingsJSON, visualSettingsJSON []byte

    err := row.Scan(
        &config.ID,
        &config.OverlayID,
        &displaySettingsJSON,
        &filterSettingsJSON,
        &config.Enable7TV,
        &config.EnableBTTV,
        &config.EnableFFZ,
        &config.CustomCSS,
        &visualSettingsJSON,
        &config.CreatedAt,
        &config.UpdatedAt,
    )
    if err != nil {
        if errors.Is(err, pgx.ErrNoRows) {
            return nil, fmt.Errorf("overlay config not found")
        }
        return nil, fmt.Errorf("failed to scan overlay config: %w", err)
    }

    if err := json.Unmarshal(displaySettingsJSON, &config.DisplaySettings); err != nil {
        config.DisplaySettings = map[string]any{}
    }
    if err := json.Unmarshal(filterSettingsJSON, &config.FilterSettings); err != nil {
        config.FilterSettings = map[string]any{}
    }
    if err := json.Unmarshal(visualSettingsJSON, &config.VisualSettings); err != nil {
        config.VisualSettings = map[string]any{}
    }

    config.EnsureMaps()
    return config, nil
}
```
