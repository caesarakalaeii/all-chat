Debounce pattern (no library, inline):
```tsx
const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null)
const debouncedSaveColor = useCallback((color: string) => {
  if (timerRef.current) clearTimeout(timerRef.current)
  timerRef.current = setTimeout(() => {
    if (/^#[0-9a-fA-F]{6}$/.test(color)) saveColor(color)
  }, 400)
}, [])
// Native color swatch onChange fires saveColor immediately (no debounce)
// Hex text input onChange fires debouncedSaveColor
```
