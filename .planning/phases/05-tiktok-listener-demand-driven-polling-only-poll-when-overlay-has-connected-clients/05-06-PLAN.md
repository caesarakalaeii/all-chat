    Verify the full demand signal flow end-to-end by running all services and checking logs.

    Complete demand-driven listener activation system has been built:
    - source-manager subscribes to overlay:connections, resolves demand per source, publishes to source:demand
    - Go SDK demand loop filters source:demand by platform and calls ChannelManager.UpdateDemandedSourceIDs
    - TikTok listener DemandSubscriber replaces pollActiveStreams, gates LiveStreamPoller
    - Kick-listener gates WebSocket subscriptions via reconcileDemand
    - youtube-listener-innertube gates discovery/polling via UpdateDemandedChannels
    - youtube-listener gates stream sync via UpdateDemandedChannels
    - discord-listener gates message publishing via DemandChecker

    Steps for human verification:
    1. Start full environment: `make docker-up`
    2. Wait 30 seconds for all services to initialize
    3. Check source-manager logs: `docker compose logs source-manager | grep -i demand`
       Expected: "Starting demand subscriber" and "Subscribed to overlay:connections"
    4. Open an overlay in browser: http://localhost:3000/overlay/{id}
       (Use an overlay that has at least one TikTok or Kick source configured)
    5. Check source-manager logs again: should show "Publishing demand update" with source count > 0
    6. Check tiktok-listener logs: `docker compose logs tiktok-listener | grep -i demand`
       Expected: "Demand update received" with correct demanded_count
    7. Check kick-listener logs: `docker compose logs kick-listener | grep -i demand`
       Expected: "Demand update received" with platform_sources > 0 (if kick sources exist)
    8. Check youtube-listener-innertube logs: `docker compose logs youtube-listener-innertube | grep -i demand`
       Expected: "Demand update received" followed by "Demanded channels updated"
    9. Close the overlay browser tab
    10. Wait 70 seconds (60s API Gateway grace period + 10s buffer)
    11. Check source-manager logs: should show demand update with 0 sources
    12. Check tiktok-listener logs: should show "LiveStreamPoller stopped (zero demand)" or "Zero demand"
    13. Check kick-listener logs: should show demand drop (0 platform_sources)
    14. Verify no error-level log entries in any service: `docker compose logs | grep -i "level=error\|\"level\":\"error\""`
  </action>
