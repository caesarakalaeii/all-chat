    **Step 4: Create demand.go with demand subscriber loop**

    New file: `shared/listener/demand.go`

    Define DemandUpdate type matching source-manager's output:
    ```go
    type demandUpdate struct {
        Type      string              `json:"type"`
        Sources   []demandUpdateSource `json:"sources"`
        Timestamp string              `json:"timestamp"`
    }

    type demandUpdateSource struct {
        SourceID  string `json:"source_id"`
        ChannelID string `json:"channel_id"`
        Platform  string `json:"platform"`
        OverlayID string `json:"overlay_id"`
    }
    ```

    `startDemandSubscriberLoop(ctx context.Context, mgr ChannelManager)`:
    - `defer b.wg.Done()`
    - nil-check b.redisClient (same as migration subscriber)
    - If b.config.DisableDemandFiltering: call `mgr.UpdateDemandedSourceIDs(nil)` to signal "no filtering" and return immediately
    - Outer retry loop with exponential backoff (1s to 30s), matching `startMigrationSubscriberLoop` pattern exactly
    - Subscribe to `"source:demand"` channel via `b.redisClient.Subscribe(ctx, "source:demand")`
    - On each message: parse JSON into demandUpdate, call `b.reconcileDemand(ctx, mgr, update)`
    - On error: log, backoff, retry

    `reconcileDemand(ctx context.Context, mgr ChannelManager, update demandUpdate)`:
    - If `!b.hasInitialAssignments.Load()`: log debug "skipping demand update, no initial assignments yet", return
    - Build demanded map: for each source in update.Sources, if `b.config.Platform == ""` or `source.Platform == b.config.Platform`, include it
    - Call `mgr.UpdateDemandedSourceIDs(demanded)` where demanded is `map[string]DemandedSource` keyed by source_id

    Also start a 60s safety-net ticker goroutine inside the loop that calls source-manager's GET /demand endpoint as fallback. Use `b.config.Platform` to filter. The coordinator client already has the base URL. Add a `DemandPollInterval` field to ListenerConfig (default 60s) and a `SourceManagerDemandURL` field (default empty, disables fallback if not set).

    IMPORTANT: The safety-net poll is optional. If `SourceManagerDemandURL` is empty, skip the fallback ticker entirely. The Pub/Sub path is the primary mechanism.

    **For each ChannelManager implementation**, add the `UpdateDemandedSourceIDs` method. The method stores the demanded sources and triggers a reconciliation of active connections.

    **Kick-listener (services/kick-listener/channels/manager.go):**

    Add a `demandedSourceIDs` field to the Manager struct:
    ```go
    demandedSourceIDs map[string]listener.DemandedSource // nil = no demand filtering (backward compat)
    ```

    Add the method:
    ```go
    func (m *Manager) UpdateDemandedSourceIDs(demanded map[string]listener.DemandedSource) {
        m.mu.Lock()
        m.demandedSourceIDs = demanded
        m.mu.Unlock()
        // Trigger reconciliation — disconnect sources that lost demand
        m.reconcileDemand()
    }
    ```

    Add `reconcileDemand()` which iterates active channels: if a channel's source_id is not in demandedSourceIDs, disconnect it. If a demanded source is not active, it will be connected on the next Start cycle.

    Modify the existing connect logic to check demand: before connecting to a source, verify it exists in demandedSourceIDs (or demandedSourceIDs is nil for backward compat).
