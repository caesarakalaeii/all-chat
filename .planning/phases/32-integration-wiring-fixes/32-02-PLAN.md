<objective>
Fix the overlay WebSocket message handler to parse `msg.user.name_gradient` from a raw JSON string to a `NameGradient` object before messages reach the render path. The Go message processor serializes the gradient as a JSON string; the TypeScript `UserInfo` interface types it as `NameGradient`. Without the parse guard, `buildGradientCSS` receives a string and throws a TypeError on `g.colors.join()`.

Purpose: Gradient usernames crash silently in the overlay. The extension (`ChatContainer.tsx`) already applies `JSON.parse` in a `useMemo` — this fix mirrors that pattern in the overlay page.

Output: One new test file (Wave 0), one line-range change in page.tsx for each of two branches (`chat_message` and `message_update`).
</objective>
