Create `services/source-manager/coordination/throttler.go`:

**Throttler struct:**
- redisClient (*redis.Client) - Cooldown and history storage
- cooldownDuration (time.Duration) - 5 minutes per CONTEXT.md
- thrashingWindow (time.Duration) - 15 minutes
- thrashingThreshold (int) - 3 rebalances
- escalationThreshold (float64) - 0.4 ratio increase (e.g., 0.6 → 1.0)
- metrics (*metrics.ShardMetrics)
- logger (*zap.Logger)

**Redis keys:**
- `rebalancing:cooldown` (string) - RFC3339 timestamp of last rebalancing, TTL=5min
- `rebalancing:history` (sorted set) - score=timestamp, member=rebalance_id, cleanup old entries
- `rebalancing:last_ratio` (string) - Last observed imbalance ratio (for escalation comparison)

**CheckCooldown(ctx context.Context, currentRatio float64) (bool, string, error):**
- Get last rebalancing timestamp: lastRebalance, err := r.Get(ctx, "rebalancing:cooldown").Result()
- If err == redis.Nil, no cooldown active → return true, "ok", nil
- Parse timestamp, calculate elapsed = time.Since(lastTime)
- If elapsed < cooldownDuration:
  - Check escalation override:
    - Get previousRatio from redis: previousRatio, _ := r.Get(ctx, "rebalancing:last_ratio").Float64()
    - ratioIncrease = currentRatio - previousRatio
    - If ratioIncrease > escalationThreshold (0.4):
      - Log warning: "Cooldown overridden by escalation" (elapsed, ratioIncrease)
      - metrics.RebalancingCooldownOverrides.Inc()
      - Return true, "escalation_override", nil
  - Cooldown still active: return false, "cooldown_active (remaining: Xs)", nil
- Cooldown expired, check thrashing:
  - isThrashing, err := r.detectThrashing(ctx)
  - If isThrashing: return false, "thrashing_detected", nil
- Return true, "ok", nil

**detectThrashing(ctx context.Context) (bool, error):**
- Calculate cutoff = time.Now().Add(-thrashingWindow).Unix()
- Query Redis Sorted Set: count, err := r.ZCount(ctx, "rebalancing:history", cutoff, "+inf").Result()
- If count >= thrashingThreshold:
  - Log error: "Thrashing detected" (rebalances_in_window, threshold, window)
  - metrics.RebalancingThrashing.Inc()
  - **Thrashing response strategy** per RESEARCH.md Claude's discretion: Alert-only (log error, enforce cooldown, let operators investigate)
    - Rationale: Thrashing indicates pathological load or misconfigured HPA, automated response may mask root cause
  - Return true, nil
- Return false, nil

**RecordRebalancing(ctx context.Context, rebalanceID string, imbalanceRatio float64) error:**
- now := time.Now()
- Pipeline:
  - Set cooldown key: SET rebalancing:cooldown {now.RFC3339} EX 300
  - Add to history: ZADD rebalancing:history {now.Unix()} {rebalanceID}
  - Store current ratio: SET rebalancing:last_ratio {imbalanceRatio}
  - Cleanup old history: ZREMRANGEBYSCORE rebalancing:history -inf {cutoff}
- Execute pipeline
- Update metrics: metrics.RebalancingTotal.Inc()
- Return error if pipeline fails

Replace existing rebalancing trigger with throttled version:

```go
if report.ShouldRebalance {
    // Check cooldown before triggering rebalancing
    allowed, reason, err := c.throttler.CheckCooldown(ctx, report.ImbalanceRatio)
    if err != nil {
        c.logger.Error("Failed to check cooldown", zap.Error(err))
    } else if !allowed {
        c.logger.Info("Rebalancing skipped", zap.String("reason", reason))
        return nil
    }

    c.logger.Info("Load imbalance detected, planning rebalancing",
        zap.Float64("imbalance_ratio", report.ImbalanceRatio),
        zap.Int("incomplete_attempts", c.incompleteRebalancingAttempts),
    )

    // Plan rebalancing migrations
    plans, err := c.rebalancer.PlanRebalancing(ctx, loads, report.AvgLoad, c.incompleteRebalancingAttempts)
    if err != nil {
        c.logger.Error("Failed to plan rebalancing", zap.Error(err))
    } else {
        // Execute migration plans
        err := c.executeRebalancingPlans(ctx, plans, sourceMap)
        if err == nil {
            // Record successful rebalancing
            rebalanceID := fmt.Sprintf("rebalance-%d", time.Now().UnixNano())
            c.throttler.RecordRebalancing(ctx, rebalanceID, report.ImbalanceRatio)

            // Check if imbalance persists after rebalancing (incomplete)
            // Next cycle will detect if ratio is still high
            c.incompleteRebalancingAttempts++
        }
    }
} else {
    // Reset incomplete counter when system is balanced
    if c.incompleteRebalancingAttempts > 0 {
        c.logger.Info("System balanced, resetting incomplete counter",
            zap.Int("previous_attempts", c.incompleteRebalancingAttempts))
        c.incompleteRebalancingAttempts = 0
    }
}
```
