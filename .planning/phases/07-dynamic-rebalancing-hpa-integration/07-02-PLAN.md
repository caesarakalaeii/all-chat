**PlanRebalancing(ctx context.Context, loads []PodLoad, avgLoad float64) ([]MigrationPlan, error):**
- Separate pods into overloaded (load > avgLoad) and underutilized (load < avgLoad)
- If no underutilized pods available, return error "no underutilized pods"
- Sort overloaded pods by load score descending (highest load first)
- Initialize targetIdx = 0 for round-robin target selection
- For each overloaded pod:
  - Query all assigned channels: assignments, err := r.registry.GetAssignmentsForPod(ctx, podID)
  - Get per-channel message rates: channelLoads := r.getChannelLoads(ctx, assignments)
  - **Proportional strategy** per CONTEXT.md: Sort channelLoads by MessageRate ascending (lowest traffic first)
    - Rationale: "Prefer moving many low-traffic channels over few high-traffic channels (reduces migration risk)"
  - Apply 20% limit: maxMigrations = int(float64(len(assignments)) * 0.20)
    - If maxMigrations == 0, set to 1 (always allow at least 1 channel to migrate)
  - Select bottom maxMigrations channels (lowest traffic)
  - Round-robin target selection: targetPod = underutilized[targetIdx % len(underutilized)]
  - Increment targetIdx for next iteration
  - Build MigrationPlan with selected channels and target pod
  - Log plan: "Planned migration from={sourcePod} to={targetPod} channels={count} ratio={X%}"
- Return []MigrationPlan

**getChannelLoads(ctx context.Context, assignments []Assignment) []ChannelLoad:**
- For each assignment (channel):
  - Query Prometheus: `rate(listener_messages_received_total{channel_id="X"}[5m])` (5-minute window for stability)
  - If query fails or returns 0, default to rate=0.0 (treat as low-traffic)
  - Append ChannelLoad{ChannelID: assignment.SourceID, MessageRate: rate}
- Return []ChannelLoad array
- Sort caller's responsibility (PlanRebalancing handles sorting)

**getHotChannels(channelLoads []ChannelLoad, avgRate float64) []string:**
- Filter channels where MessageRate > (avgRate * 3.0) per REBAL-04 requirement
- Return list of hot channel IDs
- Used for logging/metrics, not for channel selection (proportional strategy takes precedence)

```go
// Step 2.5: Monitor pod loads and check for imbalance
loads, err := c.loadMonitor.MonitorPodLoads(ctx, podIDs)
if err != nil {
    c.logger.Error("Failed to monitor pod loads", zap.Error(err))
    // Continue with normal reconciliation
} else {
    report := c.loadMonitor.CalculateImbalance(loads)

    if report.ShouldRebalance {
        c.logger.Info("Load imbalance detected, planning rebalancing",
            zap.Float64("imbalance_ratio", report.ImbalanceRatio),
            zap.Float64("max_message_rate", report.MaxMessageRate),
            zap.String("reason", report.Reason),
        )

        // Plan rebalancing migrations
        plans, err := c.rebalancer.PlanRebalancing(ctx, loads, report.AvgLoad)
        if err != nil {
            c.logger.Error("Failed to plan rebalancing", zap.Error(err))
        } else {
            // Execute migration plans (triggers are sufficient, no waiting yet)
            c.executeRebalancingPlans(ctx, plans, sourceMap)
        }
    } else {
        c.logger.Debug("No rebalancing needed", zap.String("reason", report.Reason))
    }
}
```
