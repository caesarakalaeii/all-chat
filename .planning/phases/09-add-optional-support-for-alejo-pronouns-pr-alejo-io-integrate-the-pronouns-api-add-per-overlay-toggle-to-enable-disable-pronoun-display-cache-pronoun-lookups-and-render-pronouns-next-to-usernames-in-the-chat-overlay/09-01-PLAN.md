<objective>
Add the PronounEnricher to the message-processor service. This creates the Go enricher that fetches pronouns from the Alejo API (api.pronouns.alejo.io/v1/), caches results in Redis with 24h TTL, extends the ViewerBadgeEnricher DB query to resolve linked Twitch usernames for cross-platform pronoun lookup, and wires the enricher into the CHAT PATH of cmd/main.go.

Purpose: Backend pipeline enrichment is the foundation — frontend rendering depends on the `pronouns` field being populated on messages.
Output: PronounEnricher, extended UserInfo model, pipeline wiring, unit tests.
</objective>

    Package: `enricher`

    Constants:

    const (
        PronounCacheTTL       = 24 * time.Hour

    ```go
    type alejoPronounDef struct {
        Name     string `json:"name"`
        Subject  string `json:"subject"`
        Object   string `json:"object"`
        Singular bool   `json:"singular"`
    }

    type alejoUserResponse struct {
        ChannelID    string  `json:"channel_id"`
        ChannelLogin string  `json:"channel_login"`
        PronounID    string  `json:"pronoun_id"`
        AltPronounID *string `json:"alt_pronoun_id"`
    }
    ```

    Struct:
    ```go
    type PronounEnricher struct {
        httpClient   *http.Client
        redisClient  *redis.Client
        logger       *zap.Logger
        pronounsMap  map[string]alejoPronounDef // loaded once at construction
    }
    ```

    Constructor `NewPronounEnricher(redisClient *redis.Client, logger *zap.Logger) *PronounEnricher`:
    - Create `http.Client{Timeout: 3 * time.Second}`
    - Fetch pronouns map from `https://api.pronouns.alejo.io/v1/pronouns` at construction time
    - If fetch fails, log warning and use empty map (graceful degradation)
    - Return `&PronounEnricher{...}`

    Method `Enrich(ctx context.Context, msg *models.UnifiedChatMessage) error`:
    1. Resolve twitch username: if `msg.Platform == "twitch"`, use `strings.ToLower(msg.User.Username)`; otherwise use `strings.ToLower(msg.User.TwitchUsername)`. If empty, return nil.
    2. Cache check: `pronoun:{twitch_username}` key. On hit: if empty string sentinel, return nil (no pronouns). If non-empty, set `msg.User.Pronouns = cached` and return nil. On `redis.Nil`, proceed to fetch.
    3. HTTP GET `{alejoAPIBaseURL}/users/{twitch_username}`. On 404: cache empty sentinel `""` with 24h TTL, return nil. On any other error: log warning, return nil (D-05 silent skip).
    4. Parse `alejoUserResponse`. Build display text using `buildDisplayText(resp.PronounID, resp.AltPronounID, e.pronounsMap)`.
    5. Cache display text in Redis with 24h TTL.
    6. Set `msg.User.Pronouns = displayText` if non-empty.
    7. Return nil.

    Helper `buildDisplayText(primaryID string, altID *string, pronounsMap map[string]alejoPronounDef) string`:
    - Look up `primaryID` in map. If not found, return `primaryID` as fallback.
    - If `altID != nil && *altID != ""`: look up alt in map, return `strings.ToLower(primary.Subject) + "/" + strings.ToLower(alt.Subject)`.
    - If `primary.Singular`: return `strings.ToLower(primary.Subject)` (e.g. "any", "other").
    - Else: return `strings.ToLower(primary.Subject) + "/" + strings.ToLower(primary.Object)` (e.g. "he/him").
