## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, pronoun pill internal horizontal padding |
| sm | 8px | Compact element spacing, gap between pill and username |
| md | 16px | Default element spacing, form row gaps |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Source: `globals.css` `--spacing-*` tokens. Matches existing `--spacing-1` through `--spacing-16` scale.

Exceptions:
- Pronoun pill vertical padding: 2px (half-step, required to maintain pill inline height matching badge height of 18px)
- Touch targets for toggle controls: 44px minimum height (existing ToggleSwitch height already satisfies this)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`--text-base`) | 400 | 1.5 |
| Label / sub-text | 13px (`--text-sm`) | 400 | 1.4 |
| Heading | 16px (`--text-lg`) | 600 | 1.2 |
| Display | 20px (`--text-xl`) | 600 | 1.2 |

Source: `globals.css` typography tokens. Matches existing overlay page and appearance panel typography.

Pronoun pill specific:
- Font size: 11px (`--text-xs`)
- Font weight: 600 (semibold — matches existing platform badge text style `text-xs font-semibold uppercase`)
- Letter-spacing: normal (no uppercase transform — pronouns are mixed case e.g. "she/her")

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-bg` = `oklch(0.09 0.007 270)` | Page background, overlay canvas |
| Secondary (30%) | `--color-surface` = `oklch(0.11 0.009 270)` / `--color-surface-2` = `oklch(0.14 0.008 270)` | Appearance panel, settings cards, form rows |
| Accent (10%) | `--color-twitch` = `#a37bff` | Primary CTAs, active state indicators, radio button accent (`accent-twitch`) |
| Destructive | `#ef4444` (red-500) | Destructive actions only (not applicable in this phase) |

Source: `globals.css` design tokens. Confirmed by existing `VisibilityGroup.tsx` and `ColorPickerControl.tsx` usage.

Accent reserved for: save/apply button, active toggle thumb, radio button check marks. Never used on pronoun pill background (that uses the user-configured `pronoun_color`).

### Pronoun Pill Color Contract

- Default pill background: `#7B68EE` (medium slate blue — neutral, inclusive, readable on dark overlay backgrounds). This value is set server-side as the `pronoun_color` default when `show_pronouns` is first enabled.
- Pill text color: white (`#ffffff`) — always white regardless of configured background (sufficient contrast for all reasonable background choices; WCAG AA at 4.5:1 requires white for any hue darker than ~40% lightness)
- Color picker for `pronoun_color`: uses existing `ColorPickerControl` component (HexColorPicker) — no new color infrastructure needed
- Pill background renders at full opacity (no opacity modifier)

## Component Inventory

### New: Pronoun Pill (overlay renderer)

Rendered inline in `frontend/src/app/overlay/[id]/page.tsx` next to the username.

```
<span
  className="inline-flex items-center rounded-full px-1.5 py-0.5 text-[11px] font-semibold leading-none text-white"
  style={{ backgroundColor: pronounColor }}
>
  {pronouns}
</span>
```

- `rounded-full` maps to `--radius-full: 9999px` — pill shape matching badge appearance
- `px-1.5` = 6px horizontal padding (1.5 × 4px = 6px — nearest token to 4px that avoids text clipping)
- `py-0.5` = 2px vertical padding
- Inline-flex with `items-center` — aligns with badge height of 18px
- Gap from username: `gap-1` (4px) — consistent with badge gap in the existing badge row

### Modified: VisibilityGroup (appearance panel)

Add a new collapsible sub-section following the "Show platform indicators" block, using the same `border-t border-border pt-3` divider pattern:

```
{/* Pronouns */}
<div className="border-t border-border pt-3">
  <ToggleSwitch
    label="Show pronouns"
    checked={pronounsVisible}
    onChange={...}
  />
  <div className={`mt-2 space-y-2 pl-2 ${!pronounsVisible ? 'pointer-events-none opacity-40' : ''}`}>
    <div>
      <p className="mb-1 text-xs text-text-sub">Position</p>
      <RadioGroup name="pronounPosition" options={PRONOUN_POSITION_OPTIONS} ... />
    </div>
    <div>
      <ColorPickerControl label="Pill color" value={pronounColor} onChange={...} />
    </div>
  </div>
</div>
```

- `pointer-events-none opacity-40` disabled state matches existing platform badge sub-section pattern exactly (from `VisibilityGroup.tsx` line 120)
- `RadioGroup` is the existing internal `RadioGroup<T>` component already defined in `VisibilityGroup.tsx` — no new import needed
- `ColorPickerControl` is imported from `./ColorPickerControl` — already used in `ColorsGroup.tsx`

### Modified: VisualSettings (types)

Add to `frontend/src/lib/types/visual-settings.ts`:

```typescript
showPronouns?: 'inline' | 'none'      // --chat-show-pronouns
pronounPosition?: 'before' | 'after'  // not CSS-driven, stored for persistence

```

Pattern: mirrors `showPlatformBadge`, `platformBadgePosition`, `platformBadgeStyle` — same inline/none toggle + non-CSS config fields.

### Modified: DisplaySettings (overlay.ts)

Add to `frontend/src/lib/types/overlay.ts` `DisplaySettings` interface:

```typescript
show_pronouns?: boolean
pronoun_position?: 'before' | 'after'
pronoun_color?: string
```

Pattern: mirrors `show_platform_badge`, `platform_badge_position`, `platform_badge_style` — snake_case for API/DB fields.

### Modified: UserInfo (message.ts)

Add to `frontend/src/lib/types/message.ts` `UserInfo` interface:

```typescript
pronouns?: string  // e.g. "she/her", "they/them" — absent if no pronouns set or feature disabled
```

## Interaction States

### Pronoun pill in overlay

| State | Appearance |
|-------|------------|
| Pronouns present, show_pronouns on | Colored pill rendered at configured position |
| Pronouns absent (no Alejo data) | No pill rendered — zero space, no placeholder |
| show_pronouns off | No pill rendered — as if field absent |
| API unreachable during enrichment | No pill rendered — silent skip per D-05 |

### Pronoun toggle in VisibilityGroup

| State | Appearance |
|-------|------------|
| Toggle on | Position radio + color picker visible, full opacity |
| Toggle off | Position radio + color picker visible but `opacity-40 pointer-events-none` |
| Default (new overlay) | Toggle on, position "after", color `#7B68EE` |

### Position radio

| Value | Effect |
|-------|--------|
| Before username | Pill renders before display name in the username row |
| After username | Pill renders after display name (default) |

Default: "After username" — mirrors platform badge default of "before" but chosen as "after" because pronouns are secondary context, not a leading identifier.

## Layout: Username Row in Overlay

The username row renders inline elements left-to-right. With all features on:

```
[platform-badge] [badges...] [avatar] [pronoun-pill] [display-name]
```
or with pronoun position "after":
```
[platform-badge] [badges...] [avatar] [display-name] [pronoun-pill]
```

Exact implementation follows the existing `platformBadgePosition === 'before'` / `'after'` conditional pattern in `page.tsx` — two render sites (before and after username block).

## Accessibility

- Pronoun pill carries no `aria-label` — the text content ("she/her") is self-describing; screen readers read inline text directly

- Toggle uses existing `ToggleSwitch` component — already accessible
