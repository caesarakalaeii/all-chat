**File: handlers/health.go**

Health check handlers (TIKTOK-05):
1. **LiveHandler:** Always returns 200 OK
2. **ReadyHandler:**
   - Check connection status (at least one TikTokLiveClient connected)
   - Check assignment count > 0 (coordinator responded)
   - Check active connections >= assignments (all channels connected)
   - Return 503 if any check fails, 200 if all pass

Per CONTEXT.md: "Ready status: Pod reports ready AFTER successfully connecting to all assigned channels"
