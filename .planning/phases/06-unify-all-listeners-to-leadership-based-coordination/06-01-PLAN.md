    **Per D-06:** Merge ListenerBase into LeadershipListener as a standalone struct (no embedding).

    **1. Rewrite `shared/listener/leadership.go`:**

    Create `LeadershipConfig` struct with these fields only:
    ```go
    type LeadershipConfig struct {
        Platform              string
        DisableDemandFiltering bool
    }
    ```
    Remove: HeartbeatInterval, AssignmentRefreshInterval, StartupJitterMax, DisableCoordinatorFiltering, OnFatalError (all per D-08).

    Create `LeadershipListener` struct (standalone, no embed):
    ```go
    type LeadershipListener struct {
        config      LeadershipConfig
        redisClient *redis.Client
        logger      *zap.Logger
        coordinator *sourcemanager.LeadershipCoordinator
        smClient    *sourcemanager.Client
        cancel      context.CancelFunc
        wg          sync.WaitGroup
    }
    ```

    `NewLeadershipListenerFromEnv(platform string, redisClient *redis.Client, logger *zap.Logger) (*LeadershipListener, error)`:
    - Read `SOURCE_MANAGER_SECRET` and `SOURCE_MANAGER_URL` from env (same pattern as current)
    - When SECRET absent, return LeadershipListener with nil coordinator (same nil-safe behavior)
    - Set config.Platform = platform
    - Set config.DisableDemandFiltering = false (default; callers override after construction)

    `NewLeadershipListener(config LeadershipConfig, redisClient *redis.Client, logger *zap.Logger) (*LeadershipListener, error)`:
    - Config-based constructor for tests (no env reads)
    - Returns LeadershipListener with nil coordinator/smClient

    `Start(ctx context.Context, mgr ChannelManager) error`:
    - Call `mgr.Start(ctx)` directly (no startup jitter, no initial assignment query)
    - Create internal context with cancel
    - If NOT DisableDemandFiltering AND redisClient != nil: `wg.Add(1)` + `go ll.startDemandSubscriberLoop(internalCtx, mgr)`
    - Return nil

    `Stop()`:
    - Call cancel if non-nil
    - Wait on wg

    Keep existing `LeadershipCoordinator()` and `SMClient()` accessors unchanged.

    **2. Move demand loop methods to LeadershipListener receiver:**

    In `shared/listener/demand.go`, change all method receivers from `(b *ListenerBase)` to `(ll *LeadershipListener)`.
    - `startDemandSubscriberLoop` receiver: `(ll *LeadershipListener)`
    - `runDemandSubscriber` receiver: `(ll *LeadershipListener)`
    - `reconcileDemand` receiver: `(ll *LeadershipListener)`

    Simplify `reconcileDemand` — remove the `hasInitialAssignments` guard and the `assignedSourceIDs` intersection:
    ```go
    func (ll *LeadershipListener) reconcileDemand(mgr ChannelManager, update demandUpdate) {
        demanded := make(map[string]DemandedSource, len(update.Sources))
        for _, src := range update.Sources {
            if ll.config.Platform != "" && src.Platform != ll.config.Platform {
                continue
            }
            demanded[src.SourceID] = DemandedSource{
                SourceID:  src.SourceID,
                ChannelID: src.ChannelID,
                Platform:  src.Platform,
                OverlayID: src.OverlayID,
            }
        }
        if ll.logger != nil {
            ll.logger.Debug("Demand update reconciled",
                zap.Int("total_in_update", len(update.Sources)),
                zap.Int("demanded_after_filter", len(demanded)),
                zap.String("platform_filter", ll.config.Platform),
            )
        }
        mgr.UpdateDemandedSourceIDs(demanded)
    }
    ```

    **3. Update `shared/listener/channel_manager.go`:**

    Remove `HandleMigrationEvent(event *coordination.MigrationEvent) error` from the `ChannelManager` interface.
    Remove the import of `github.com/caesar/all-chat/shared/coordination`.
    The interface should have 6 methods:
    ```go
    type ChannelManager interface {
        Start(ctx context.Context) error
        Stop()
        UpdateAssignedSourceIDs(newAssignedIDs map[string]bool)
        UpdateDemandedSourceIDs(demanded map[string]DemandedSource)
        GetFilteredAssignmentCount() int
        GetActiveChannels() []string
        GetActiveChannelCount() int
    }
    ```
    Note: Keep `UpdateAssignedSourceIDs` as a no-op slot per research open question 1. It stays in the interface but no SDK code calls it.

    **4. Update `shared/listener/config.go`:**

    Keep the `Env()` helper function (used across all listeners).
    Remove `ListenerConfig` struct entirely.
    Remove `DefaultConfig()` function entirely.
    The `LeadershipConfig` is defined in leadership.go (step 1).

    **5. Update `shared/listener/shutdown.go`:**

    Change `ShutdownCoordinator` first parameter from `*ListenerBase` to `interface{ Stop() }`:
    ```go
    func ShutdownCoordinator(listener interface{ Stop() }, mgr ChannelManager, platformDisconnect func(), srv *http.Server, logger *zap.Logger) {
        var wg sync.WaitGroup
        wg.Add(2)
        go func() { defer wg.Done(); mgr.Stop() }()
        go func() { defer wg.Done(); listener.Stop() }()
        wg.Wait()
        // ... rest unchanged
    }
    ```

    **6. Delete `shared/listener/base.go`** entirely. All its content is either merged into leadership.go or removed.

    **7. Delete `shared/listener/testutil/mock_coordinator.go`** — the `coordinatorClient` interface no longer exists.
