  <behavior>
    - NewRingBufferPublisher(capacity int, publishFn, logger) creates buffer with given capacity
    - Publish(ctx, payload) with working publishFn calls publishFn directly, does not buffer
    - Publish(ctx, payload) with failing publishFn enqueues to ring buffer, returns nil (caller unaware)
    - When ring buffer has items, retry goroutine calls publishFn every 500ms with context.Background()
    - When retry succeeds, item is removed from buffer
    - When buffer is full (capacity reached), Enqueue drops oldest message and increments drops counter
    - Stop() signals retry goroutine to exit and waits for it
    - After Stop(), Publish returns error indicating shutdown
    - ring_buffer_depth gauge reflects current buffer size
    - ring_buffer_drops_total counter increments on overflow
  </behavior>

    ```go
    package listener

    import (
        "context"
        "sync"
        "time"

        "github.com/prometheus/client_golang/prometheus"
        "github.com/prometheus/client_golang/prometheus/promauto"
        "go.uber.org/zap"
    )
    ```

    **Types:**
    ```go
    // PublishFunc is the underlying publish operation the ring buffer wraps.
    type PublishFunc func(ctx context.Context, payload []byte) error

    // RingBufferPublisher wraps a publish function with an in-memory ring buffer
    // that retries failed publishes. Opt-in per D-07.
    type RingBufferPublisher struct {
        publishFn PublishFunc
        logger    *zap.Logger

        mu       sync.Mutex
        buf      []bufferedMsg
        head     int
        tail     int
        size     int
        capacity int

        stopCh  chan struct{}
        stopped bool
        wg      sync.WaitGroup

        // Metrics
        depth      prometheus.Gauge
        dropsTotal prometheus.Counter
    }

    type bufferedMsg struct {
        payload    []byte
        enqueuedAt time.Time
    }
    ```

    **Constructor:**
    ```go
    func NewRingBufferPublisher(capacity int, publishFn PublishFunc, logger *zap.Logger, serviceName string) *RingBufferPublisher {
        rb := &RingBufferPublisher{
            publishFn: publishFn,
            logger:    logger,
            buf:       make([]bufferedMsg, capacity),
            capacity:  capacity,
            stopCh:    make(chan struct{}),
            depth: promauto.NewGauge(prometheus.GaugeOpts{
                Name:        "ring_buffer_depth",
                Help:        "Current number of messages in the publish retry ring buffer",
                ConstLabels: prometheus.Labels{"service": serviceName},
            }),
            dropsTotal: promauto.NewCounter(prometheus.CounterOpts{
                Name:        "ring_buffer_drops_total",
                Help:        "Total messages dropped from ring buffer due to capacity overflow",
                ConstLabels: prometheus.Labels{"service": serviceName},
            }),
        }
        rb.wg.Add(1)
        go rb.retryLoop()
        return rb
    }
    ```

    **Publish method:**
    ```go
    func (rb *RingBufferPublisher) Publish(ctx context.Context, payload []byte) error {
        if err := rb.publishFn(ctx, payload); err != nil {
            rb.enqueue(payload)
            rb.logger.Warn("Publish failed — buffered for retry",
                zap.Int("buffer_depth", rb.getSize()),
                zap.Error(err))
            return nil // Caller does not see the error — message is buffered
        }
        return nil
    }
    ```

    **Enqueue (internal):**
    - Lock mutex
    - If `size == capacity`: advance head (drop oldest), decrement size, increment `dropsTotal`, log Warn "ring buffer full — dropping oldest message"
    - Write to `buf[tail]`, advance tail, increment size
    - Update `depth` gauge

    **retryLoop (internal):**
    - Ticker at 500ms
    - On each tick: lock mutex, peek head item, unlock, try `publishFn(context.Background(), item.payload)`. On success: lock, dequeue (advance head, decrement size, update depth gauge), unlock. On failure: leave in buffer for next tick.
    - Exit on stopCh close

    **Stop:**
    ```go
    func (rb *RingBufferPublisher) Stop() {
        rb.mu.Lock()
        rb.stopped = true
        rb.mu.Unlock()
        close(rb.stopCh)
        rb.wg.Wait()
    }
    ```
