## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Spoofing | Custom URL pointing to malicious audio | accept | Browser CORS policy limits cross-origin reads; only audio playback triggered, not script execution. el.src assignment is safe. |
| T-12-02 | Tampering | XSS via custom URL in DOM | mitigate | Never inject notification_sound_url into innerHTML. Only assign to el.src which is a safe DOM property. |
| T-12-03 | Elevation of Privilege | Premium bypass editing localStorage | accept | D-07 explicitly accepts frontend-only gate. Overlay page is public, only authenticated owner can save config. |
| T-12-04 | Spoofing | Malicious postMessage from other origin | accept | Embed page already accepts postMessage from any origin (existing pattern for VISUAL_CSS_UPDATE, FILTER_SETTINGS_UPDATE). Sound settings follow same pattern. |
</threat_model>
