## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05 | Tampering | Custom URL stored in display_settings | accept | Backend stores display_settings as map[string]any — no schema validation needed. URL only used as el.src (safe assignment). Same trust model as existing custom_css field. |
| T-12-06 | Elevation of Privilege | Non-premium user inspects HTML, removes disabled attr | accept | D-07 explicitly accepts frontend-only gate. The saved config is only writable by the authenticated overlay owner. Premium gate is UX-only, not security. |
| T-12-07 | Information Disclosure | Sound settings visible in postMessage | accept | postMessage to iframe is same-origin (editor to embed preview). No sensitive data in sound settings. |
</threat_model>
