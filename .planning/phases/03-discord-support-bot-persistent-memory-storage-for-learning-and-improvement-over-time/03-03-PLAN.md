1. Add a new init container `run-migrations` to `support-bot-deployment.yaml` as the FIRST init container (before clone-all-chat). This uses the `postgres:16-alpine` image which has `psql` available. Embed the migration SQL directly in the command for idempotency (PostgreSQL CREATE TYPE does NOT support IF NOT EXISTS, so use a DO $$ block):

   ```yaml
   - name: run-migrations
     image: postgres:16-alpine
     command:
       - sh
       - -c
       - |
         PGPASSWORD="$DATABASE_PASSWORD" psql \
           -h "$DATABASE_HOST" \
           -p "$DATABASE_PORT" \
           -U "$DATABASE_USER" \
           -d "$DATABASE_NAME" \
           -v ON_ERROR_STOP=0 \
           -c "DO \$\$ BEGIN IF NOT EXISTS (SELECT 1 FROM pg_type WHERE typname = 'memory_type') THEN CREATE TYPE memory_type AS ENUM ('error_pattern', 'correction', 'codebase_insight'); END IF; END \$\$;" \
           -c "CREATE TABLE IF NOT EXISTS bot_memories (id SERIAL PRIMARY KEY, type memory_type NOT NULL, tags TEXT[] NOT NULL DEFAULT '{}', content TEXT NOT NULL, access_count INTEGER NOT NULL DEFAULT 0, created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(), updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW());" \
           -c "CREATE INDEX IF NOT EXISTS idx_bot_memories_tags ON bot_memories USING GIN (tags);" \
           -c "CREATE INDEX IF NOT EXISTS idx_bot_memories_updated_at ON bot_memories (updated_at DESC);"
     envFrom:
       - configMapRef:
           name: allchat-config
     env:
       - name: DATABASE_PASSWORD
         valueFrom:
           secretKeyRef:
             name: allchat-secrets
             key: database-password
   ```

2. Add DATABASE_URL env var to the main `support-bot` container using Kubernetes variable substitution. Add these env vars at the END of the existing env block (order matters for K8s `$(VAR)` resolution):

   ```yaml
   - name: DATABASE_HOST
     value: "allchat-cluster-rw.allchat.svc.cluster.local"
   - name: DATABASE_PORT
     value: "5432"
   - name: DATABASE_NAME
     value: "allchat"
   - name: DATABASE_USER
     value: "allchat_user"
   - name: DATABASE_PASSWORD
     valueFrom:
       secretKeyRef:
         name: allchat-secrets
         key: database-password
   - name: DATABASE_URL
     value: "postgresql://$(DATABASE_USER):$(DATABASE_PASSWORD)@$(DATABASE_HOST):$(DATABASE_PORT)/$(DATABASE_NAME)"
   ```

3. Preserve all existing init containers (clone-all-chat, clone-all-chat-extension, register-slash-commands), env vars, volumes, and other configuration unchanged.
