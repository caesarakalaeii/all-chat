1. **Add deletion event detection to ParseMessages():**
   - Existing ParseMessages() handles addChatItemAction (regular messages)
   - Add new case for markChatItemAsDeletedAction:
     ```go
     for _, action := range response.ContinuationContents.LiveChatContinuation.Actions {
         if action.AddChatItemAction != nil {
             // Existing message parsing (Phase 9)
             msg, err := parseRegularMessage(action.AddChatItemAction)
             // ...
         } else if action.MarkChatItemAsDeletedAction != nil {
             // NEW: Deletion event parsing
             delEvent, err := parseDeletionEvent(action.MarkChatItemAsDeletedAction)
             if err != nil {
                 logger.Warn("Failed to parse deletion event", zap.Error(err))
                 continue
             }
             messages = append(messages, delEvent)
         }
     }
     ```

2. **Implement parseDeletionEvent():**
   ```go
   func parseDeletionEvent(action *MarkChatItemAsDeletedAction) (*models.RawChatMessage, error) {
       // Extract deleted message ID
       deletedMessageID := action.DeletedStateMessage.Runs[0].Text // or targetItemId

       // Create RawChatMessage with deletion event type
       return &models.RawChatMessage{
           MessageID:   uuid.New().String(), // New ID for deletion event itself
           Platform:    "youtube",
           ChannelID:   "", // Populated by caller
           Username:    "",
           DisplayName: "",
           Message:     "",
           Timestamp:   time.Now(), // Or extract from action.TimestampUsec
           EventType:   "message_deletion",
           Metadata: map[string]interface{}{
               "deleted_message_id": deletedMessageID,
               "deletion_type":      "single",
           },
       }, nil
   }
   ```

3. **InnerTube deletion event structure:**
   - Add to types.go:
     ```go
     type MarkChatItemAsDeletedAction struct {
         DeletedStateMessage struct {
             Runs []struct {
                 Text string `json:"text"`
             } `json:"runs"`
         } `json:"deletedStateMessage"`
         TargetItemId string `json:"targetItemId"`
     }
     ```

**Schema reference from Phase 1 (v1.0):**
Official youtube-listener deletion event format:
```json
{
  "message_id": "uuid-for-deletion-event",
  "platform": "youtube",
  "event_type": "message_deletion",
  "metadata": {
    "deleted_message_id": "original-message-id",
    "deletion_type": "single"
  }
}
```

**Why this approach:** Extend existing parser rather than create new module. Deletion events are just another action type from InnerTube. Reuse RawChatMessage schema (EventType field already exists from Phase 1).
