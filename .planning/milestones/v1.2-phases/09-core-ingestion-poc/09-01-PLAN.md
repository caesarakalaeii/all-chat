  <action>
Build message parser that converts InnerTube ChatAction objects to RawChatMessage format, with strict schema validation to ensure byte-for-byte compatibility with official youtube-listener.

1. **Core Parsing Function**:
   - `ParseMessages(actions []ChatAction, channelID string) ([]*models.RawChatMessage, error)`
   - Iterate over `actions[]` array from InnerTube response
   - Extract message text, user metadata (username, userID, avatar), timestamp
   - Generate UUID for MessageID using `github.com/google/uuid`
   - Set Platform="youtube", populate ChannelID from parameter

2. **Field Mapping** (InnerTube → RawChatMessage):
   - `message.runs[].text` → `Text` (concatenate all runs)
   - `authorExternalChannelId` → `UserID`
   - `authorName.simpleText` → `Username`
   - `timestampUsec` / 1000000 → `Timestamp` (convert microseconds to time.Time)
   - `StreamID` → empty string (not provided by InnerTube, will be set by control plane in Phase 10)
   - `Tags` → empty map (no tags in PoC scope)
   - `EventType`, `EventData` → omit for regular messages (defer to Phase 13)

3. **Strict Validation Function**:
   - `ValidateRawMessage(msg *models.RawChatMessage) error`
   - Critical fields (MessageID, Platform, UserID, Username, Text, Timestamp) must be non-empty
   - Platform must equal "youtube"
   - Timestamp must not be zero value
   - If Tags is nil, initialize to empty map `make(map[string]string)`
   - Fail entire message if critical fields missing (log error, return nil for that message)
   - Use sensible defaults for optional fields (empty arrays, null)

4. **Drop Extra InnerTube Fields**:
   - Do NOT include: `contextMenuAccessibility`, `trackingParams`, `contextMenuEndpoint`
   - Only copy fields that exist in official youtube-listener RawChatMessage schema
   - Refer to services/youtube-listener/models/raw_message.go lines 8-24 as canonical schema

**Implementation reference**: Research RESEARCH.md section "Architecture Patterns > Pattern 3: Strict Message Validation" lines 205-242

**Critical constraint**: Byte-for-byte match with official youtube-listener output. Any extra fields break the contract with message-processor (user decision from CONTEXT.md).
