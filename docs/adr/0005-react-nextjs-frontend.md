# ADR-0005: React + Next.js App Router

**Date**: 2025-11-11
**Status**: Accepted
**Revised**: 2026-11-18
**Deciders**: Frontend Lead, Architecture Team

## Context

The frontend covers the admin dashboard (login, overlay management, source configuration), the public overlay display (real-time chat with 7TV/BTTV/FFZ emotes over WebSocket), and the landing page (needs SEO). Most of the code is generated by agents, so the generation accuracy of the framework matters as much as its features. Decision-time trials measured roughly 90% first-try accuracy for React, 70% Vue, 50% Angular, 40% Svelte.

## Decision

Use React 19 + Next.js 16+ (App Router) with TypeScript for the whole frontend.

Rationale: highest agent generation accuracy (largest training corpus, so fewest manual fixes), server rendering and static generation for the landing page's SEO and crawlability of overlay pages, a large component ecosystem (shadcn/ui on Base UI primitives, see `frontend/DESIGN_SYSTEM.md`), abundant WebSocket examples, and strong TypeScript support.

Trade-offs: larger base bundle than Vue or Svelte (~100KB); mitigated by Server Components on server-rendered pages, with client JS limited to what needs interactivity. SSR hydration mismatches (timestamps, random IDs) are handled with `useEffect` for client-only code.

Alternatives rejected: Vue/Nuxt (less training data, smaller component ecosystem, unfamiliar to the team); Angular (verbose, lowest accuracy, steep learning curve); Svelte/SvelteKit (smallest bundle but least training data and least mature ecosystem); plain HTML/JS (no SSR, routing, or state management, far slower to develop, agents assume a framework anyway).

## Implementation

- App lives in `frontend/src/app/` (App Router): landing page, `overlays/` editor, `dashboard/`, public `overlay/[id]/`, `upgrade/`.
- Components in `frontend/src/components/` (shadcn/ui under `ui/`), hooks in `src/hooks/` (`useOverlayStream` owns the WebSocket rules), utilities and the i18n catalog in `src/lib/`.
- WebSocket: native WebSocket client (`src/lib/api/websocket.ts`), no Socket.IO; reconnect with exponential backoff, `?since=` replay watermark, id dedup.
- Styling: Tailwind CSS + shadcn/ui; state: Zustand.
- Design rules: `frontend/DESIGN_SYSTEM.md`.
