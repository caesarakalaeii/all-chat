All-Chat (https://allch.at) is a chat monitoring and engagement tool that helps content creators manage and view messages from multiple streaming platforms in one centralized interface.

**TikTok Integration Purpose:**
We are implementing TikTok OAuth authentication in preparation for TikTok's official Live Chat API. Once available, users will connect their TikTok account to monitor live stream chat messages alongside other platforms like Twitch and YouTube.

**How It Works:**
1. User authenticates via TikTok OAuth in our dashboard
2. During live streams, we poll TikTok's Live Chat API for new messages
3. Messages are displayed in our centralized chat monitoring interface
4. Creators can view and respond to all platform chats in one place

**Scopes Requested:**
- user.info.basic: Identify authenticated user
- video.list: Detect active live streams
- live.room.info: Access live chat messages

**Data Usage:**
We only access live chat data during active streams. Messages are temporarily stored (24-48h) for monitoring purposes. No videos, followers, or other personal content are accessed. Users can revoke access anytime.

**Use Case:** Multistream creators monitor unified chat from all platforms in one interface, improving response time and audience engagement.
