Help

Link with All-Chat is the normal way to connect this key: press it, approve the device in the browser window that opens, and nothing needs to be copied. The credential is bound to the one overlay you pick, and you can revoke it at allch.at/settings/devices.

If linking cannot work here — a Stream Deck driving a second PC, a headless capture box, no browser on this machine — the plugin shows an eight-character pairing code instead. Enter it at allch.at/link on any device you are signed in on.

Or paste a token: mint a personal access token at allch.at/settings/api-tokens and paste the whole string, including the allchat_pat_ prefix. This stays supported and is the right choice for a machine linking cannot reach.

Leave Server empty unless you self-host All-Chat; it defaults to https://allch.at.

Sending chat messages is free on every All-Chat account.
